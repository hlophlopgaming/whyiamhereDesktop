# Changelog

All notable changes are documented here. The project follows
[Semantic Versioning](https://semver.org/).

## [Unreleased]

## [0.2.0] - 2026-10-06

### Added

- Goal suggestions from the ten most recent unique goals for each application.
- Quick duration buttons for 5, 15 and 30 minutes.
- English and Russian interfaces, original icon and logos.
- Optional SIGKILL mode and an immediate end-session button.
- Standard Python packaging, release workflow and issue forms.

### Fixed

- Installed application IDs ending in `.desktop`, including Telegram.
- Self-window exclusion and demo startup without an unsolicited goal form.

## [0.1.0] - 2026-10-06

### Added

- Initial Plasma 6 / Wayland application with KWin detection, shared sessions,
  countdown reminders, tray controls, autostart and normal window closing.
